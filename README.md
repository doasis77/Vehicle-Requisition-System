# Vehicle Requisition System

A web-based vehicle requisition portal for employees to request company vehicles for business use.

## Features

- Employee ID and department capture
- Vehicle type selection (Sedan, SUV, Van, Truck)
- Purpose and date range for the request
- Clean, responsive form UI with Font Awesome icons
- Client-side form validation

## Usage

Open the frontend in a browser:

```bash
# Open directly
start frontend/index.html

# Or serve the frontend folder
cd frontend
npx serve .
```
